Agentic AI in 50 Days

The plan I'm following to learn agentic AI, coming from 15+ years of Python, Spark and SQL. It skips the basics an experienced engineer already knows and covers the whole field: how models work, tools, retrieval, context, frameworks, multi-agent systems, evals, safety and deployment. Each day takes about an hour. Fridays are lighter, for finishing the week's build or catching up, and weekends are off. Days marked data edge lean on big data experience. Tick days off as you go; progress is saved in your browser.

Rules that make this work

  1. Build the same day you read. If time runs out, cut the reading, not the code.
  2. Keep one Git repo for the whole plan, with a folder per week. By the end it is your portfolio.
  3. Use Claude Code or Cursor on your real work every day. Watching a good harness work teaches you the design.
  4. Missed a day? Use Friday to catch up. Don't skip a build day to stay on schedule.
  5. Ignore new frameworks until Week 5. The fundamentals (tool loop, context, retrieval, evals, state) don't change.
